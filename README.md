# Gitree

Gitree 是一个交互式 Git 管理软件，使用类似 Vim 的键位逻辑来管理 Git 操作。基于 Python 开发，旨在提供一个高效、直观的 Git 仓库管理体验。

## 特性

- 类似 Vim 的键盘操作逻辑，提升操作效率
- 交互式界面，直观展示 Git 状态
- 支持常见的 Git 操作（提交、推送、拉取、分支管理等）
- 轻量级设计，快速响应

## 使用

Gitree 采用类似 Vim 的按键操作：
- `j/k`: 上下移动光标
- `h/l`: 左右切换面板
- `Enter`: 确认选择
- 其他 Git 操作快捷键...
